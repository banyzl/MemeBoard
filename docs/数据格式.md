# 数据格式 v1

Canonical database 为 `~/Library/Application Support/MemeBoard/database.json`：

```json
{
  "schemaVersion": 1,
  "memes": [
    {
      "id": "7d31c15e-1111-4111-8111-000000000001",
      "name": "猫猫无语",
      "fileName": "7d31c15e-1111-4111-8111-000000000001.png",
      "originalExtension": "png",
      "aliases": ["无语猫", "沉默猫"],
      "tags": ["猫", "无语"],
      "triggers": ["maomaowuyu", "mmwy"],
      "favorite": false,
      "createdAt": "2026-10-28T16:00:00.000Z",
      "updatedAt": "2026-10-28T16:00:00.000Z"
    }
  ]
}
```

UUID 与图片路径不随改名变化。名称全局唯一，名称比较会忽略首尾空格、进行 NFC 规范化，并忽略字母大小写。快捷码全局唯一、以英文字母开头，随后仅含小写字母和数字，最长 64 位。名称、别名与标签为 1～128 字，不允许控制字符、TSV 分隔符或图片提示使用的括号。

未填写快捷码时自动生成完整拼音；首字母缩写仅在不冲突时加入。完整拼音冲突会拒绝保存，需更名或明确填写替代快捷码，绝不静默覆盖。填写快捷码后使用用户指定的完整集合。编辑时保留表单中的已有快捷码；改名后如需重新生成拼音，清空快捷码字段保存。

`metadata` 可选且为 JSON 对象，为将来扩展保留；V1 不写入 AI 信息。编辑操作保留已有未知字段。将来的数据库升级需要显式 migration；V1 遇到未知 `schemaVersion` 会拒绝写入，不擅自覆盖。

Rime 派生索引为 UTF-8 TSV，不带表头：

```text
T<TAB>mmwy<TAB>7d31c15e-1111-4111-8111-000000000001<TAB>猫猫无语
N<TAB>猫猫无语<TAB>7d31c15e-1111-4111-8111-000000000001<TAB>猫猫无语
```

一张图片每个 trigger 一条 T 记录，名称一条 N 记录。Lua 只读取派生索引，不解析 JSON，不访问原始图片，也不进行模糊搜索。

`version` 为一次发布唯一的 UUID 字符串。发布顺序为数据库 → index.tsv → version，均独立原子替换。它不是跨三个文件的原子事务：中途失败时 canonical database 保持有效，派生文件可通过 Repair 重新生成。Lua 仅在版本变化时重新加载；解析失败或加载前后版本不同保留旧缓存。版本检查每秒最多一次，输入变化触发，不需要重新部署。

Helper 仅接受 `paste <UUID>`、`copy <UUID>` 或只读 `doctor`。它从默认数据目录按 UUID 查找图片，验证路径不能越出 images 目录，不接受名称、外部路径或 shell 字符串作为图片参数。Lua 只向固定安装路径传递经严格验证的 UUID，并对 shell 参数加引号。
